# Task Tracker CLI App

This is a simple Command Line Interface (CLI) based Task Tracker application built using Java.

## 🚀 Features
- Add a task
- Update a task
- Delete a task
- Mark task as done
- View all tasks

## 🛠️ Tech Stack
- Java (Core Java)
- CLI based application

## 📌 Project URL
https://roadmap.sh/projects/task-tracker

## ▶️ How to Run
1. Clone the repository
2. Compile the Java files
3. Run the main class from terminal
